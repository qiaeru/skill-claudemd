# CLAUDE.md

## Commands

- Build: `make` (needs `arm-none-eabi-gcc` on PATH, see README).
- Tests: `make test`; one test: `make test-one T=<name>`.

## Gotchas

- `build/config.yaml` is regenerated by `make gen` from `config.in`; edit `config.in`, never the output.
- The firmware targets a 32-bit MCU: `size_t` is 4 bytes and `long` is 4 bytes, so never assume 64-bit arithmetic in shared headers.
- `make test` runs on the host, not the target; anything touching registers must be behind `#ifdef HOST_TEST`.

## Style

- No dynamic allocation after `init()`; the allocator is disabled at runtime.
