# users-api

A Node.js REST API for managing users and teams, built with Express and PostgreSQL.

## Getting started

```bash
npm install
docker compose up redis postgres
npm run dev
```

## Scripts

See `package.json`. The usual ones: `npm run dev`, `npm run build`, `npm test`, `npm run lint`.
